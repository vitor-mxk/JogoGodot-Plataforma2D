# 🎮 Jogo de Plataforma 2D - Godot 4.7.2

Este é um projeto de jogo de plataforma 2D desenvolvido do zero, criado para colocar em prática conceitos de desenvolvimento de jogos, movimentação, e gerenciamento de cenas. 

## 📖 Sobre o Projeto

Este repositório contém o progresso e os estudos baseados na série **"Tutorial Godot do Zero 2025"**, ministrada pelo canal **Rafael Forbeck | Game Dev**. O objetivo do curso é construir um jogo de plataforma 2D completo, cobrindo desde a configuração inicial da engine até funcionalidades mais avançadas.

🔗 **Link da Playlist:** [Tutorial Godot do Zero 2025 - Plataforma 2D](https://www.youtube.com/watch?v=O7R87B_xCs8&list=PLNlPErl_v81vNINVVotsh0nYBBSp4LEgY)

## 🛠️ Tecnologias Utilizadas

* **Motor Gráfico:** Godot Engine 4.7.2 📎 Download da Godot: https://godotengine.org/
* **Linguagem:** GDScript

 ## 🛠️ Assets
 
 * Sprites e Tilesets 📎 Download: https://grafxkid.itch.io/
 

## 🚀 Como rodar o projeto localmente

Caso queira baixar e abrir este projeto na sua máquina:

1. Certifique-se de ter a Godot Engine instalada no seu computador.
2. Clone este repositório executando no terminal:
   ```bash
   git clone https://github.com/vitor-mxk/JogoGodot-Plataforma2D.git

3. Abra a Godot, clique no botão Import (Importar).

4. Navegue até a pasta clonada e selecione o arquivo project.godot.

5. Clique em "Import & Edit".
